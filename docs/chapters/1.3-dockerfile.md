# 1.3 — Construire l'image avec un Dockerfile

Le tag `1.3` ajoute une image de production reproductible pour l'API AdonisJS.

## Ce que fait le Dockerfile

1. Installe les dépendances avec pnpm dans une étape dédiée afin de profiter du cache Docker.
2. Compile TypeScript et les fichiers AdonisJS dans une étape `build`.
3. Copie uniquement `build/` dans une image runtime Node.js 24 slim.
4. Installe les dépendances de production, passe à l'utilisateur non privilégié `node` et expose le port `3333`.
5. Déclare `/health` comme `HEALTHCHECK` Docker.

## Atelier

```sh
docker build -t demo-fyc-api:1.3 .
docker run --rm \
  --env-file .env \
  -e HOST=0.0.0.0 \
  -p 3333:3333 \
  demo-fyc-api:1.3
```

Le conteneur a toujours besoin d'un PostgreSQL accessible et d'une `APP_KEY` fournie par l'environnement. L'image ne contient aucun fichier `.env`.

Pour observer le cache, modifier un fichier dans `app/`, reconstruire l'image et comparer les étapes avec une modification de `package.json`.
