# 1.1 — Socle applicatif et choix d'hébergement

Ce checkpoint correspond au premier état stable du fil rouge. L'application est une API AdonisJS/TypeScript avec PostgreSQL et expose deux familles de routes :

- `/health` et `/ready` pour observer le processus et sa capacité à joindre PostgreSQL ;
- `/api/products` et `/api/tweets` pour disposer d'une charge fonctionnelle simple à déployer.

## Objectif apprenant

Savoir expliquer ce qui est déployé avant de choisir un support : serveur dédié, VPS, instance cloud, conteneur ou cluster. Le dépôt reste volontairement simple afin que les différences d'infrastructure restent visibles.

## Vérification

Depuis un poste équipé de Node.js 24+, pnpm 11+ et PostgreSQL :

```sh
pnpm install --frozen-lockfile
cp .env.example .env
node ace generate:key
node ace migration:run
pnpm dev
```

Dans un autre terminal :

```sh
curl -i http://localhost:3333/health
curl -i http://localhost:3333/api/products
```

Le tag `1.1` est le point de départ du module 1. Il ne contient encore ni image Docker ni manifeste Kubernetes.
