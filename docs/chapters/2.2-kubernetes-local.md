# 2.2 — Kubernetes local : Deployment, Service et probes

Le tag `2.2` ajoute les manifestes de la stack complète dans `deploy/kubernetes/local/`.

## Ordre pédagogique

1. `00-namespace.yaml` isole les ressources de l'atelier.
2. `01-db.yaml` crée un Secret de TP, un Service PostgreSQL, un Deployment et un PVC.
3. `02-config.yaml` sépare la configuration non sensible de l'image.
4. `03-migration-job.yaml` exécute la migration une fois, au lieu de la lancer dans chaque Pod API.
5. `04-api.yaml` crée trois Pods via un Deployment et les expose par un Service ClusterIP.
6. `05-ingress.yaml` propose une entrée HTTP si un contrôleur Nginx est présent.

La sonde `/health` répond à la question « le processus vit-il ? ». La sonde `/ready` répond à « l'API peut-elle joindre PostgreSQL ? ». Kubernetes ne route le trafic que vers les Pods prêts.

Les valeurs du Secret sont des valeurs de laboratoire. Elles illustrent le mécanisme Kubernetes mais ne constituent pas une gestion de secrets de production.
