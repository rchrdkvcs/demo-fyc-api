# 4.2 — Base commune et overlays Kustomize

Le tag `4.2` ajoute `deploy/kustomize/`.

## Lecture de l'arborescence

- `base/` contient les ressources communes : API, PostgreSQL, PVC, probes, Job de migration et configuration ;
- `overlays/staging/` garde un seul réplica et un namespace de test ;
- `overlays/production/` passe l'API à trois réplicas et utilise un namespace séparé ;
- `images` remplace l'image locale par le tag publié dans GHCR.

Le même manifeste peut donc être relu dans deux contextes sans copier-coller. Le contenu sensible doit être remplacé par un Secret externe ou un mécanisme de chiffrement adapté avant la production.
