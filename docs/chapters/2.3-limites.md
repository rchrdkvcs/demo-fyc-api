# 2.3 — Les limites d'une machine

## Ce que ce checkpoint ajoute

Aucun code : une grille de panne à remplir sur le VPS du chapitre 2.2. Elle
sert de bilan au TP2 et motive le passage à un cluster (module 3).

## Lancer

Garder une sonde qui tourne pendant chaque scénario, depuis le poste de travail :

```sh
while true; do
  printf '%s ' "$(date +%T)"
  curl -s -o /dev/null -w '%{http_code}\n' --max-time 2 https://api.mon-domaine.fr/ready
  sleep 1
done
```

## Grille de panne

| Scénario | Commande sur le VPS | Résultat attendu | Coupure mesurée | Qui répare ? |
| --- | --- | --- | --- | --- |
| Crash de l'API | `sudo kill -9 <pid du conteneur api>` | Docker relance le conteneur (`restart: unless-stopped`) | quelques secondes | Docker |
| Arrêt manuel | `sudo docker compose stop api` | `502` côté Nginx jusqu'au redémarrage | jusqu'à intervention | Un humain |
| Base arrêtée | `sudo docker compose stop db` | `/health` = `200`, `/ready` = `503` | jusqu'à intervention | Un humain |
| Redémarrage du serveur | `sudo reboot` | Tout revient seul après le boot | ~30 s à 2 min | systemd + Docker |
| Mise à jour de l'image | changer `API_TAG`, `docker compose up -d` | Ancien conteneur arrêté avant le nouveau | quelques secondes | Un humain |
| Panne du VPS | arrêt depuis la console de l'hébergeur | Plus rien ne répond, données sur un seul disque | jusqu'à intervention | Un humain |
| Montée en charge | `hey -z 30s -c 50 https://api.mon-domaine.fr/api/tweets` | Latence en hausse, CPU d'une seule machine saturé | — | Personne : pas de scaling |

## Observer

- **Point unique de défaillance (SPOF)** : un seul serveur, une seule base, un seul disque.
- **Mise à jour = coupure** : Compose remplace le conteneur, il ne fait pas de rolling update.
- **Scaling vertical seulement** : plus de CPU/RAM sur la même machine, avec redémarrage.
- **Réparation manuelle** : Docker relance un processus, pas une machine.

Ces quatre limites sont exactement ce que Kubernetes adresse au module 3 :
plusieurs nœuds, état désiré réconcilié, rolling update et HPA.
