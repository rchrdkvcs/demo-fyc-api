# 3.1 — Cloud public et Kubernetes managé

Le tag `3.1` ajoute l'extension `deploy/kubernetes/cloud/`. Elle conserve les manifestes applicatifs du module 2 et montre le point d'intégration avec un Kubernetes managé.

## Ce qui change

- le control plane est opéré par le fournisseur ;
- le Service `LoadBalancer` demande une entrée réseau managée ;
- le PVC du manifeste PostgreSQL est provisionné par la `StorageClass` du cluster ;
- les règles d'identité, réseau, coût et disponibilité dépendent du fournisseur choisi.

## Ce qui ne change pas

L'image, le port, les probes et la séparation entre configuration et secret restent ceux du fil rouge. L'objectif est d'identifier les responsabilités déléguées, pas de mémoriser une commande propre à AWS, Scaleway ou GCP.

Avant de lancer le TP, vérifier le prix courant, les quotas et la politique de suppression du fournisseur. Un compte d'essai ou un free-tier peut changer ; ce dépôt ne promet pas de crédit gratuit.
